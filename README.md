TensegrityDataLocator

A tiny browser-based prototype to record candidate per-module pose/orientation time-series files associated with a paper. Paste URLs and sample text/snippets (no network access). Produces a JSON report per candidate suitable for guiding data replay or follow-up requests.

How to use
- Open index.html in a browser.
- Enter paper title/DOI and candidate URLs.
- For each candidate, paste sample file text or small excerpts and add notes.
- Click "Generate JSON Report" and save or copy the output.

Limitations
- No automatic crawling or downloads. Designed as a careful human-assisted checklist and recorder.
